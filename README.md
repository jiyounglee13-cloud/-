# 세계사 동시대 비교 타임라인 (East–West–Korea Synchronic Timeline)

하나의 시간축 위에 **유럽 · 동아시아 · 남아시아/이슬람 · 한국** 4개 문화권을 병렬 레인으로 배치해,
"어떤 사건이 일어난 그 시점에 다른 문화권은 무엇을 하고 있었나"를 한눈에 비교하는 웹앱입니다.

각 사건은 **① 객관적 사실(`description`)** 과 **② 세계사적 의미·해석(`significance`)** 을 분리해 보여줍니다.

## 기술 스택

- **Vite + React + TypeScript + Tailwind CSS**
- 타임라인: **D3 스케일 + 커스텀 SVG** (D3는 스케일 계산, SVG는 React가 렌더)
- 데이터: **JSON + Zod 스키마** (타입·런타임 검증 단일 소스)
- 배포: 정적(Vercel 자동 감지, `vite build → dist/`)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run validate   # 시드 데이터 무결성 검증(CI 게이트)
npm run build      # 프로덕션 빌드(dist/)
npm run typecheck  # 타입 검사
```

## 데이터 모델 (`src/data/events.json`)

`src/types/event.ts` 의 Zod 스키마가 타입과 검증의 단일 소스입니다.

| 필드 | 설명 |
| --- | --- |
| `id` | 안정적 slug |
| `title` | 사건명 |
| `era` / `yearStart` / `yearEnd?` | 시대(BCE/CE) · 시작/종료 연도(범위 없으면 생략) |
| `track` | `europe` \| `eastasia` \| `south_asia_islam` \| `korea` |
| `category` | 정치 \| 전쟁 \| 문화 \| 과학기술 \| 종교 \| 경제 |
| `importance` | 1~5 (줌/필터용) |
| `description` | **객관적 사실만** |
| `significance` | **세계사적 의미·해석** (사실과 혼용 금지) |
| `sources` | 출처 배열 `{ label, url? }` (모든 이벤트 필수) |
| `contested` / `contestedNote?` | 연대·해석 논쟁 여부 및 근거 |
| `region?` | 트랙 내 세부(예: 남아시아·이슬람 → 압바스/무굴/굽타) |
| `related?` | 타입 있는 연결 `{ id, type, note? }` — `인과` \| `영향` \| `동시대(무관)` |

## 정확성 규칙

- 연대·인물·사건은 **통설**을 따르고, 불확실하면 `contested=true` + 범위/근거로 표시합니다.
- `description`(사실)과 `significance`(해석)을 절대 섞지 않으며, 화면에서도 색·영역으로 구분합니다.
- **모든 이벤트에 출처**를 남깁니다(검증 스크립트가 강제). URL이 불확실하면 지어내지 않고 출처명만 남깁니다.
- "동양"을 하나로 뭉개지 않고 **동아시아**와 **남아시아·이슬람**을 별도 트랙으로 둡니다.
- 같은 연도라는 이유만으로 인과처럼 엮지 않습니다 — `동시대(무관)` 타입으로 **우연적 동시성**을 명시합니다.
  (예: 조선 갑인자 1434 ↔ 구텐베르크 c.1450 은 **독립 발명**으로 표기)

## 시드 데이터

동시대 대비가 극적인 밀집 클러스터 중심으로 **57건**(BCE 고대사 ~ 20세기):

- **기원전 5세기 (축의 시대)**: 아테네 민주정 · 그리스-페르시아 전쟁 · 공자 · 붓다
- **기원전 3~2세기 (제국의 시대)**: 알렉산드로스 · 포에니 전쟁 · 진 통일 · 마우리아(아소카) · 고조선
- **7세기**: 당 건국 · 헤지라 · 하르샤 제국 · 신라 삼국통일
- **8세기 전후**: 발해 건국 · 압바스/바그다드 · 카롤루스 대관 · 안사의 난
- **10~11세기**: 고려 건국 · 송 건국 · 가즈나 인도 원정 · 제1차 십자군
- **13세기**: 몽골 제국 · 델리 술탄국 · 마그나카르타 · 팔만대장경
- **15세기 중반(핵심)**: 구텐베르크 · 콘스탄티노플 함락 · 훈민정음/갑인자/측우기 · 로디 왕조
- **16세기말~17세기초**: 임진왜란 · 갈릴레오 · 세키가하라 · 무굴 악바르
- **19세기(근대)**: 다윈 『종의 기원』 · 세포이 항쟁 · 메이지 유신 · 강화도 조약
- **20세기(세계대전·전후)**: 신해혁명 · 1·2차 세계대전 · 러시아 혁명 · 3·1운동 · 인도 독립 · 광복/한국전쟁 · 중화인민공화국

## 접근성 · 반응형

- **키보드**: 타임라인 사건 마커는 Tab으로 포커스, Enter/Space로 상세 열기. 모든 상호작용 요소에 포커스 링(`:focus-visible`).
- **스크린리더**: 마커에 `role="button"`·`aria-label`(사건명·연대·문화권·분류), 상세는 `role="dialog"`+`aria-modal`, 필터 컨트롤에 `aria-label`/`aria-pressed`.
- **모바일**: 좁은 화면에서 좌측 레인 여백 축소, 비교 패널은 타임라인 아래로 세로 배치, 필터 바 자동 줄바꿈.

## AI 보조 설명 (선택)

사건 상세에서 ‘사실’과 ‘의미’를 쉽게 풀어주는 **보조 설명**을 AI로 생성할 수 있습니다(실험적).

- 서버리스 함수 `api/explain`(Vercel Node 런타임)에서만 Anthropic API를 호출하며, **API 키는 브라우저에 노출되지 않습니다.**
- 배포 환경 변수에 `ANTHROPIC_API_KEY`(선택 `ANTHROPIC_MODEL`, 기본 `claude-opus-5`)를 설정하면 활성화됩니다. 미설정 시 앱은 정상 동작하고 AI 설명만 ‘미구성’ 안내를 표시합니다.
- 로컬에서는 `npm run dev`가 같은 로직을 처리합니다(`vite preview`는 정적 서빙만 하므로 AI 기능은 dev에서 확인).
- **정확성 원칙:** 시스템 프롬프트로 “주어진 사실/의미만 재구성하고 새 사실·연대·인물·출처를 지어내지 말 것”을 강제합니다. UI에는 **‘출처 없음 · AI 생성’**을 명시하며, 항상 상단의 사실·출처를 우선하도록 안내합니다.
