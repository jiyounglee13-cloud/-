# 🎓 이과 대입 전략 상담 프로그램

**자연계열(이과) · 내신 상위권 · 현재 고1(2028학년도 대입) 남학생 전용**으로
설계된 대입 전략 상담 웹 프로그램입니다. **과목별 성적**을 입력하면
**수시(내신 기반) / 정시(수능 기반) 대시보드**로 나눠 진단하고 최적의 학교를
제안하며, 목표 대학·학과를 선택하면 부족한 점과 가중치 확보 전략을 코칭합니다.
설치나 서버 없이 브라우저만 있으면 동작합니다.
(남학생 전용이므로 여자대학교는 제외되어 있습니다.)

## ⭐ 등급 체계 (첫 화면에서 설명 카드로 안내)

| 구분 | 체계 | 비율 | 쓰이는 곳 |
| --- | --- | --- | --- |
| **내신** | **5등급 상대평가** (2025년 고1부터) | 1등급 상위 10% / 2등급 34% / 3등급 66% / 4등급 90% | 수시 (교과·종합) |
| **수능·모의고사** | **9등급 상대평가** | 1등급 상위 4% / 2등급 11% / 3등급 23% … | 정시 + 수시 최저기준 |

공개된 대학 입결(내신 컷)은 9등급제 수치이므로, 이 앱은 **백분율 기준으로
5등급제 환산 컷을 자동 계산**해 비교합니다 (`convert9to5`).

## 실행 방법

`index.html` 파일을 브라우저(크롬 등)로 열면 끝입니다. 별도 설치 불필요.

```bash
# 또는 간단한 로컬 서버로 실행
cd admissions-counselor
python3 -m http.server 8000   # → http://localhost:8000
```

## 주요 기능

### 1️⃣ 과목별 성적 입력 → 수시·정시 대시보드
- 입력
  - **내신(5등급제)**: 국어·수학·영어·사회·과학 **과목별 등급** (1.0~5.0)
  - **수능 모의고사(9등급제)**: 국어·수학·통합사회·통합과학 백분위 + 영어 등급
    (2028 수능 통합형 반영 — 통합사회·통합과학 모두 응시)
  - 희망 학과(자연계열), 이수한 내신 학기(기본값 고1 1학기)
- 출력: **대시보드** 형태
  - 🏆 **최적 학교 제안**: 수시·정시 중 유리한 경로 기준 안정 2 / 적정 2 / 도전 2
  - 📗 **수시 대시보드** (내신 기반): 수시 전형 설명 파트 + 대학별 표
    - **대학별 반영 내신 자동 계산** — 반영 교과 조합(국영수과 / 전교과 /
      상위 3·4개 교과)이 대학마다 달라 `GYOGWA_BASIS` 기준으로 각각 계산
    - 교과 70%컷을 **5등급제 환산 + 구 9등급제 병기**
    - **수능 최저학력기준 충족 판정** (2합4·3합7 등 대학·학과별 `MIN_REQUIREMENTS`)
  - 📘 **정시 대시보드** (수능 기반): 정시 전형 설명 파트 + **수능 등급컷
    참고표**(등급별 비율·백분위 하한) + 대학별 정시 70%컷(평균 병기) 판정
- 모든 컷은 **70%컷과 합격자 평균 병기**, 판정은 70%컷 기준

### 🏫 학과별 세분화 + 가중치 팁
- **의약학 계열**(의예·치의예·한의예·수의예·약학): 대학별 실제 보유 여부와
  학과별 개별 합격선(정시 백분위 / 교과 내신)을 `data.js`의 `special` 필드에 수록
- **자연계열 일반 학과 13개**: 컴퓨터공학·AI, 전자·반도체, 화공, 기계, 산업,
  건축·토목, 수학, 생명, 화학, 물리, 간호, 환경, 식품영양 — 계열 평균에 학과
  선호도 보정치(`DEPARTMENTS`의 `off`)를 적용해 학과별 예상 컷 산출
- **학과별 가중치 확보 팁**: 학과마다 [과목 선택(고교학점제) / 세특·활동 /
  수능 반영 가중치] 3종 팁을 수록 — 목표 대학 코칭 화면에 표시.
  학과 미선택 시 이과생 공통 팁(수학 30~40% 가중, 미적분/기하·과탐 지정 등) 제공
- 목표 대학 코칭 화면에 **그 대학의 학과별 예상 합격선 표**(내 성적 기준
  판정 포함)가 함께 표시됩니다

### 2️⃣ 목표 대학 맞춤 코칭
목표 대학을 선택하면 전형(경로)별로 격차를 분석해 코칭합니다.
- **정시**: 합격선까지 부족한 백분위 점수 + 가장 취약한 과목부터 보완 우선순위 제시,
  영어 등급 감점 경고
- **수시 교과**: 남은 학기 수를 반영해 "남은 N개 학기 동안 평균 몇 등급을 받아야
  하는지" 역산 — 수학적으로 불가능하면 종합·논술·정시로 전환 권고
- **수시 종합**: 합격자 내신 평균 대비 위치 + 세특·전공연계활동 코칭
- **논술**: 운영 대학인 경우 대안 경로로 안내
- **학년별 로드맵**: 이수 학기 기준으로 지금 해야 할 일 제시

### 3️⃣ 최신 데이터 반영
- 기준: **2026학년도 입시결과**(2025년 11월 수능 시행분) 및 각 대학 공개
  전년도 입시결과 기반 추정치 (합격자 평균은 70%컷에서 정시 +0.6 백분위,
  내신 -0.15등급 보정한 참고치 — `data.js`의 `avgDelta`)
- 데이터 버전이 화면 상단 배지에 항상 표시됩니다

## 데이터 갱신 방법 (매년 1회 권장)

모든 대학 데이터는 `data.js` 한 파일에 있습니다. 로직(`app.js`) 수정 없이
수치만 바꾸면 됩니다.

1. [대입정보포털 어디가](https://www.adiga.kr) → 대학별 입시결과에서 최신 수치 확인
   - 정시: 국·수·탐 평균 백분위 70%컷 → `jungsi`
   - 수시 교과: 내신 70%컷 → `gyogwa`
   - 수시 종합: 합격자 내신 평균 → `jonghap`
   - 의약학: 학과별 컷 → `special` (`j`: 정시 백분위, `g`: 교과 내신)
2. `data.js`의 해당 대학 수치 수정 (학과 선호도 변화는 `DEPARTMENTS`의 `off` 조정)
3. 맨 위 `dataVersion` 문자열 갱신 (예: `"2027학년도 입시결과 기준 (2027-06 갱신)"`)

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면(UI) |
| `data.js` | 대학별 합격선 데이터 (매년 갱신 대상) |
| `app.js` | 진단·코칭 로직 (데이터와 분리, 수정 불필요) |

## 판정 기준

| 판정 | 정시 (내 백분위 − 컷) | 수시 교과 (컷 − 내 내신) |
| --- | --- | --- |
| 안정 | +1.5 이상 | +0.3등급 이상 여유 |
| 적정 | −0.5 이상 | −0.15 이상 |
| 소신 | −2.0 이상 | −0.5 이상 |
| 도전 | −4.0 이상 | −1.0 이상 |
| 위험 | 그 미만 | 그 미만 |

## ⚠️ 유의사항

- 합격선은 공개 입시결과 기반 **참고용 추정치**이며, 실제 합격선은
  연도·모집단위(학과)·경쟁률에 따라 달라집니다.
- 일반 학과의 컷은 계열 평균 + 선호도 보정치 기반 추정으로, 같은 학과라도
  연도·경쟁률에 따라 ±1~2(백분위) 이상 변동할 수 있습니다.
- 의약학 계열은 수능 최저학력기준·수학(미적분/기하)·과탐 지정 등 별도
  요건이 있으므로 반드시 모집요강을 확인하세요.
- 최종 지원 전 반드시 공식 자료를 확인하세요:
  [어디가](https://www.adiga.kr) · [한국대학교육협의회](https://www.kcue.or.kr) ·
  각 대학 입학처
